# Robot Operating System 2 (ROS 2) With C++ & Python Tutorials — Contents

Welcome to the **ROS 2 (Humble) with C++ & Python Tutorials** series.

This series is a set of personal study notes written by me on ***ROS 2 (Humble)***. I first started to write these while learning ROS 2 from the Udemy course *ROS 2 Robotics Developer Course* (Raymond Andrade, C++ and Python editions). Over the years I have also made additions from various sources like the official ROS 2 Humble documentation, and the rclcpp and rclpy client library docs, and learnings from Youtube tutorials. It walks through ROS 2 from the ground up — setting up your development environment, understanding core concepts like nodes, topics, services, actions, and parameters, and writing publishers, subscribers, and launch files in both **C++ and Python**. Along the way there are hands-on mini-projects, and the series closes with a capstone project that combines everything into a TurtleBot3 navigation system with a custom A* planner and a full ROS 2 diagnostics setup.

Most core topics are covered twice — once in C++ and once in Python — so you can follow whichever language track fits your project, or work through both.
